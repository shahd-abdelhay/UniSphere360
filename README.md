# UniSphere 360+ — Interactive Presentation

Professional presentation website for the **AI-Powered Personalized University Ecosystem**.

## Included
- 10 presentation sections
- Student Personalized LMS UI
- Faculty AI Teaching Studio UI
- HR / Staff Operations UI
- University Admin Command Center UI
- AI Core and six AI engines
- Technical architecture
- Interactive AI workflows
- Security & responsible AI
- Graduation roadmap
- Full-screen presentation mode
- Responsive layout

## Run
Open `index.html` in any modern browser.

## GitHub Pages
Create a public repository such as `UniSphere360`, upload:
- `index.html`
- `style.css`
- `script.js`
- `README.md`

Then open **Settings → Pages → Deploy from a branch → main → / (root) → Save**.

Typical live URL:
`https://shahd-abdelha.github.io/UniSphere360/`

## Suggested implementation stack
Frontend: React / Next.js
Backend: Java 17 + Spring Boot
AI: Python + FastAPI
ML: scikit-learn / XGBoost
RAG: embeddings + Qdrant/pgvector + LLM
Database: SQL Server / PostgreSQL
CV: OpenCV + OCR + Vision Models
Voice: STT + LLM + TTS
Security: JWT / OAuth2 + RBAC
Deployment: Docker + CI/CD
